       - Function `compute_stakeholder_config(stakeholders: list) -> str`:
         - `dm_count = sum(1 for s in stakeholders if s.is_decision_maker)`
         - `total_count = len(stakeholders)`
         - if `dm_count > 1`: return `"multi_dm_multi"`
         - elif `total_count > 1`: return `"single_dm_multi"`
         - else: return `"single_dm_single"`
       - Async function `update_stakeholder_config(project_id: str, session: AsyncSession) -> str`:
         - Load all stakeholders for project via `select(Stakeholder).where(Stakeholder.project_id == project_id)`
         - Call `compute_stakeholder_config(stakeholders)`
         - Update project via `BaseRepository(Project, session).update(project_id, stakeholder_config=config)`
         - Return the computed config string

    2. Extend `backend/api/stakeholders.py`:
       - Import `from backend.services.phase1_service import update_stakeholder_config`
       - After `await session.commit()` in `create_stakeholder()`, call `await update_stakeholder_config(project_id, session)` then `await session.commit()` again
       - Same after `await session.commit()` in `update_stakeholder()` (only if `is_decision_maker` or `role` changed)
       - Same after `await session.commit()` in `delete_stakeholder()`
       - This ensures stakeholder_config is always up-to-date after any mutation

    3. Create `frontend/src/api/stakeholders.ts`:
       ```typescript
       import { apiClient } from './client'
       import type { Stakeholder } from '../types'

       export interface StakeholderCreate {
         name: string; role: string; is_decision_maker?: number
         profile?: string; interests?: string; elicitation_mode?: string
       }

       export const stakeholdersApi = {
         list: (projectId: string) => apiClient.get<Stakeholder[]>(`/api/projects/${projectId}/stakeholders`).then(r => r.data),
         create: (projectId: string, data: StakeholderCreate) => apiClient.post<Stakeholder>(`/api/projects/${projectId}/stakeholders`, data).then(r => r.data),
         update: (projectId: string, id: string, data: Partial<StakeholderCreate>) => apiClient.patch<Stakeholder>(`/api/projects/${projectId}/stakeholders/${id}`, data).then(r => r.data),
         remove: (projectId: string, id: string) => apiClient.delete(`/api/projects/${projectId}/stakeholders/${id}`),
       }
       ```
