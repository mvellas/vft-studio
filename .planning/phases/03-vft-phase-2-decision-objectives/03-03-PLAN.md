From 03-RESEARCH.md WITI classification rules:
- "Because it leads to [Other Objective]" → means, set witi_implies_objective_id, create CausalLink
- "Because it is fundamentally important" → fundamental, set is_fundamental_candidate=1
- "Because it reflects mission/vision beyond this decision" → strategic
- Unclear → other

From 03-UI-SPEC.md WITI Modal flow:
1. User clicks WITI trigger → modal opens with objective statement
2. Pre-filled question: "Por que [OBJECTIVE] e importante no contexto desta decisao?"
3. User types answer → "Classificar" CTA active
4. CTA triggers POST to /axiom/witi-classify → loading spinner
5. Result: classification badge + reasoning text
6. "Confirmar" saves to DB and updates ObjectiveCard badge; modal closes

From 03-UI-SPEC.md WITI classification result copy:
- MEANS: "Meio — Este objetivo e instrumental para atingir outro."
- FUNDAMENTAL: "Fundamental — Este objetivo e um fim em si mesmo."
- STRATEGIC: "Estrategico — Este objetivo esta alem do escopo da decisao atual."

         - Return `WITIResult(classification=classification, implies_objective_id=implies_id, reasoning=reasoning)`
