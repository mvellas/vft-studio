       - `router = APIRouter(prefix="/projects/{project_id}/attributes", tags=["attributes"])`
       - `_require_project(project_id, session)` helper
       - `GET ""` → list all attributes for project: join with Objective to get objective_id context; return `list[AttributeWithLevelsResponse]` (each attribute includes its levels)
       - `GET "/{attribute_id}"` → single attribute with levels
       - `POST ""` → create attribute: generate UUID, validate objective_id exists and belongs to project, validate attr_type in ["natural", "constructed", "proxy"], set timestamps, session.add; catch IntegrityError for unique objective_id → 409 "Attribute already exists for this objective"; return AttributeResponse with 201
       - `PUT "/{attribute_id}"` → update attribute: load, update non-None fields from AttributeUpdate, set updated_at; return AttributeResponse
       - `DELETE "/{attribute_id}"` → hard delete attribute + cascade delete its attribute_levels; return 204
       - `POST "/{attribute_id}/levels"` → create AttributeLevel: generate UUID, set created_at, session.add; return AttributeLevelResponse with 201
       - `PUT "/levels/{level_id}"` → update level: load, update non-None fields; return AttributeLevelResponse
       - `DELETE "/levels/{level_id}"` → hard delete level; return 204
       - `PUT "/{attribute_id}/levels/reorder"` → reorder levels: request body `{"level_ids": list[str]}`; update order_index for each to match list position; return 200
