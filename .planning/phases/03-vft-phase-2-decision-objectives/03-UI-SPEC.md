## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inner padding, inline list separators |
| sm | 8px | Button padding vertical, compact form element spacing |
| md | 16px | Default element spacing, card padding, textarea padding |
| lg | 24px | Section padding, card gap within objective list |
| xl | 32px | Step panel internal separation |
| 2xl | 48px | Major section breaks (step heading to content) |
| 3xl | 64px | Page-level top/bottom padding (reserved for full-page views) |

Exceptions:
- react-flow canvas: fills 100% of container, no spacing token; padding inside canvas nodes uses md (16px)
- Modal overlays: padding lg (24px) on all sides
- Objective node in react-flow graph: width 200px, height 60px (fixed, per RESEARCH.md Pattern 5)
- Touch targets for icon-only buttons (WITI trigger, delete): minimum 44px × 44px

**Source:** Standard 8-point scale; exceptions derived from RESEARCH.md Pattern 5 node dimensions and AppShell.tsx `p-6` (24px) pattern.

## Interaction Contracts

### Auto-save
- All form fields (TechniqueSelector, OrgDocumentPanel, AttributeDefiner): debounce 2000ms, same pattern as DecisionFrameForm.tsx
- Visual indicator: "Salvo" text in gray-400 fades in for 1500ms after save completes

### AI Generation / Streaming
- "Gerar com IA" buttons show spinner + disabled state during SSE stream
- Streamed text appears character-by-character in read-only textarea
- Error state replaces streamed content with error copy (see Copywriting Contract)

### WITI Modal flow
1. User clicks WITI trigger on ObjectiveCard → modal opens with objective statement displayed
2. AXIOM poses "Por que X é importante para a decisão?" pre-filled
3. User types answer → "Classificar" CTA active
4. CTA triggers POST to `/axiom/witi-classify` → loading spinner
5. Result displays: classification badge + reasoning text
6. "Confirmar" saves to DB and updates ObjectiveCard badge; modal closes

### CoC Modal flow
1. User clicks CoC trigger (only visible for FUNDAMENTAL objectives)
2. Q1 displayed; user answers; Q2 displays on "Próxima"
3. "Avaliar" triggers CoC engine; result shows alignment/refinement info
4. If `refinement_needed=true` → editable refinement textarea pre-filled by AI; "Confirmar Refinamento" CTA
5. Save updates objective statement in DB

### Means-Ends Network (react-flow)
- Canvas fills `flex-1` container (no fixed height)
- Controls panel (zoom in/out/fit) from @xyflow/react `<Controls />` component — bottom-left
- Background grid from `<Background />` — dots pattern
- "Exportar PNG" button in top-right overlay; triggers html2canvas capture
- Nodes draggable; edges non-editable from this view (editing happens via WITI modal)

### Phase 2 Completion Gate
- Progress bar in PhaseProgress shows % of fundamentals with confirmed attributes
- "Confirmar Fase 2" CTA disabled until: all objectives classified + all fundamentals have CoC + all fundamentals have AttributeDefiner complete
- On click: shows confirmation dialog ("Fase 2 completa. Avançar para Fase 3?")
